Most companies have run a cost program in the last five years. Fewer can show the savings in this year's accounts. The usual reasons are familiar: targets set top-down without a plan behind them, savings counted when a decision was taken rather than when the money left the budget, and no change to the work itself, so the cost returns when volumes do.

We build operations programs the other way round. We start with the activities that consume cost, work out which ones customers would pay for, and redesign the rest with the managers who will run them. Targets go into budgets, not trackers. Finance signs off every number before we count it.

The result is a lower cost base that holds, and an operating rhythm that keeps it there: a few metrics that matter, reviewed weekly by the people who can act on them.
